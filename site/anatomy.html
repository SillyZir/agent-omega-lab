Anatomy of one autonomous fix

A bug report went in.
A merged fix came out.
No human touched the middle.

This is the complete record of DeepSeek-Reasonix PR #9707 — the one fix Omega carried from selection to pull request with no human in the loop. Every pane below is a verbatim artifact from the published execution record or the public GitHub trail; nothing is recreated. Steps are labeled by who acted: OMEGA the system, HUMAN people outside it.

It proves the fix with a test written blind OMEGA

A separate session — deliberately never shown the fix — writes a regression test from the issue alone. The recorded verification: the test fails on the unpatched code with the user's exact symptom, and passes once the fix is applied. A third, independent review then judges whether the test actually captures the reported bug.

It reviews its own work — twice OMEGA

Two independent review passes judge the patch. (In this system the second pass exists to catch manipulation: issue text is written by strangers, so pass 2 reads a sanitized copy — a steering phrase that fooled pass 1 would make the verdicts diverge, and divergence fails the gate.)

Fifteen release gates say yes OMEGA

Deterministic checks hold the only authority to ship: budgets, capacity, scope, both judge verdicts, the verified test, content and injection lints, size caps. Any failure — or any gate that errors — would have routed this to a human instead. (The system has since grown a 16th gate; these are the fifteen in force that morning.)

The maintainer merges it HUMAN

Twenty-four days later, the project's maintainer — a person with no connection to Omega, applying their own judgment to an ordinary-looking PR — merges it. Omega did nothing in the interval except read the PR's public state once a day. The merge is entirely theirs; that is what makes it evidence.

What this does — and doesn't — prove

It proves the full loop can run unattended end-to-end and produce work a real maintainer accepts: once, on this repo, under policies that admitted it to the unattended path. It does not prove autonomy at scale — the other ten merged PRs had a human review Omega's work before shipping, which is the deliberate default. The point was never "no humans"; it's that authority lives in checks, not in the model — this is the one time the checks were the only reviewer, and the outcome held.
